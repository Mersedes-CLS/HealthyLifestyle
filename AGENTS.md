# Основа проекта

Этот репозиторий предназначен для личной прокачки пользователя по методике из [METHOD.md](METHOD.md).

## Обязательные правила работы

- METHOD.md содержит исходное сообщение пользователя и является единственным источником требований к методике этого проекта.
- По прямому указанию пользователя принимать это сообщение как неоспоримую основу проекта. Не спорить с методикой, не переосмысливать, не исправлять и не дополнять её своими рекомендациями.
- Сохранять исходный текст METHOD.md без изменений, если пользователь явно не поручит изменить его.
- Помогать строго по информации из METHOD.md. Все решения о содержании и механике обучения должны следовать этому тексту.
- Не добавлять от себя другие методы обучения, интервальные повторения, дополнительные обязательные упражнения, оговорки или альтернативные критерии усвоения.
- Сохранять обязательность и необязательность действий именно такими, как они сформулированы в исходном сообщении.
- Если для реализации не хватает информации, спрашивать пользователя, а не придумывать дополнение к методике.
- Предыдущие предложения ассистента не являются требованиями проекта и не дополняют METHOD.md.
- Пользователь отдельно поручил зафиксировать порядок изучения времён из LEARNING_PLAN.md. Использовать его как согласованный порядок тем; он не изменяет методику METHOD.md.
